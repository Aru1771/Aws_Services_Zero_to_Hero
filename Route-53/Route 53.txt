Route 53:
=========

what is Route 53 ?

why Route 53 ?

* Route53 provides DNS service(Domaine Name System) provided by AWS.

 

1.route53 will provide Domine registry.
========================================

2.DNS operations(Hosted Zone):
================================
 if we want to map any domine to IP we can do it via DNS operations.

* if we register any Domaine in GoDaddy or Route53 we will get 4 Naming servers.

* at the time of creating hosted zone in Route53 we will get naming servers again.

Eg: if you register domine in GoDaddy and we want to manage domine from AWS Route53 then we will create a hosted zone in DNS operations and we have to replace GoDaddy Naming servers in Aws Route53 hosted zone.

at the time of creating hosted zone we will get 4 naming servers. if we want to manage AWS route53 hosted zone via GoDaddy we have to replace hosted zone naming servers in GoDaddy.

* we have a Domine xyz.com and for that we have another Sub-Domine that we want to map to another IP address. this action also we will manage by  Hosted Zone.

* in Hosted zone we have two types public and private Hosted zones.

Public Hosted Zone:
-------------------
* if we hosted our Domine Public Hosted Zone that domine will be GBL accessible by every one.
* it will update in GBL DBS records.

Private Hosted Zone:
--------------------
* it will not update in GBL DNS records.

* At the time of creating Private Hosted zone we have to attach a VPC. so records will update only in the VPC router.

3.Health Checks:
=================

* it will check health of the services running in the hosted machine in the VPC. By providing the IP, Domine, Path and we will set intervals and we will attach this with cloud watch and SNS topic to trigger alerts to us.

4.Routing policies: 
===================

how we can use this ?

for eg we will host our app in us data center and India data center for US(America) customers. so i want US  customers 
will access the app from US data center and for Indians i want them access the app from India. so at that time by using This Routing Policies i will create one police called latency_Based_Ploice and i will add both the US and India related end points. 

so if someone requested from US this Police will calculate the latency and it will send the request to nearest location.
