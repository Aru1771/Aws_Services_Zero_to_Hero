What is AWS CloudTrail ?
-------------------------

* It supports governence, compliance and operational and risk audits of AWS account.
* it records all the logs and Api call's made to our aws account. wheather Aws console, SDK, CLI or other resources.


Log event types:
---------------

* Managment events: operations in resources like creating or deleting the instance.
* Data events: operations with in the resouces like uploading , deleting file to s3 it will support few resources only RDS, S3.


* Cloud Trail is region specifig
* we can see all the thing in event history.
* only 90 days events will be available
* if you required more than that we have to create a clod trail event.
* by using this event logs we will quick find the actions performed in the aws account.
